# Перевод карточек настольных игр

`boardgame-card-translations` — это прототип версии 0.1 для локального перевода текста на изображениях карточек настольных игр.

Проект пока делает простую замену текста: распознаёт английский текст, переводит его локальной LLM через Ollama, скрывает старый текст размытием фона и вписывает русский перевод поверх него.

## Что умеет версия 0.1

1. Открывает исходную картинку `input/card.png`.
2. Находит английский текст через PaddleOCR.
3. Отправляет каждый найденный текстовый блок в локальную модель `qwen3:8b` через Ollama.
4. Получает русский перевод в стиле локализации настольных игр.
5. Скрывает старый текст размытым фрагментом исходного фона.
6. Подбирает размер шрифта под найденный OCR-бокс.
7. Сохраняет готовую картинку в `output/card_ru.png`.

> Важно: это именно первая рабочая версия. Она не восстанавливает сложный фон под текстом и не имитирует оригинальный стиль карты. Для этого позже можно добавить LaMa, SDXL/FLUX для восстановления фона и более умный подбор шрифта.

## Структура проекта

```text
.
├── input/              # сюда кладём исходные изображения карт, например card.png
├── output/             # сюда сохраняются готовые переведённые изображения
├── fonts/              # сюда можно положить TTF-шрифты для кириллицы, например arial.ttf
├── modules/
│   ├── __init__.py     # делает папку modules Python-пакетом
│   ├── ocr.py          # распознавание текста и координат через PaddleOCR
│   ├── renderer.py     # скрытие старого текста и отрисовка перевода через Pillow
│   └── translator.py   # перевод через локальный Ollama API
├── main.py             # основной сценарий OCR → перевод → отрисовка
└── requirements.txt    # зависимости Python
```

## Настройка на Windows 10

Создай и активируй виртуальное окружение:

```powershell
python -m venv venv
venv\Scripts\activate
```

Установи зависимости:

```powershell
pip install -r requirements.txt
```

Установи Ollama, затем скачай и проверь модель:

```powershell
ollama run qwen3:8b
```

Внутри Ollama можно проверить перевод фразой:

```text
Translate: Deal 2 damage to all enemies.
```

## Как запустить

1. Положи исходную карту в `input/card.png`.
2. Убедись, что Ollama запущена и модель `qwen3:8b` доступна.
3. Запусти сценарий обработки:

```powershell
python main.py
```

После успешного запуска результат появится здесь:

```text
output/card_ru.png
```

## Шрифты

Модуль отрисовки сначала ищет шрифт в папке `fonts/`:

- `fonts/arial.ttf`
- `fonts/Arial.ttf`

Если таких файлов нет, на Windows используется системный шрифт:

- `C:/Windows/Fonts/arial.ttf`

Если ни один шрифт формата TrueType не найден, Pillow использует встроенный дефолтный шрифт. Он может плохо отображать кириллицу, поэтому лучше положить в `fonts/` нормальный TTF-шрифт с поддержкой русского языка.

## Ограничения версии 0.1

- Старый текст пока скрывается размытием исходного фона, а не настоящим inpainting.
- Фон под текстом восстанавливается приблизительно, поэтому на сложном арте возможны артефакты.
- Есть базовый перенос строк по словам, но без ручной вёрстки и контроля отдельных строк.
- Цвет, обводка и тень пока задаются фиксированным стилем, а не определяются по оригинальной карте.
- OCR может ошибаться на декоративных или сильно стилизованных шрифтах.
